AtGenesis ADVANCED is a radical laboratory for hardcore users who find even the ‘perfect malfunction’ of the BASIC version far too tame.

We reject even the minimal conscience possessed by low-cost SoC clone consoles of the 2010s. The ADVANCED branch offers more options.

This version focuses not merely on restoring nostalgia, but on emulating more precisely and freely.

If the BASIC version is Picasso, the ADVANCED version is an unrecognizable abstraction. We believe emulation only becomes art when it is ‘reinterpretation,’ not ‘reproduction’.

“If you want more mainstream and stable pain, go back to the BASIC branch immediately.” <br><br>

AtGenesis ADVANCED 는 BASIC 버전의 '완벽한 오작동'조차 너무나도 온순하다고 느끼는 하드코어 사용자들을 위한 급진적 실험실입니다.

우리는 2010년대 저가형 SoC 클론 콘솔이 가졌던 최소한의 양심마저 거부합니다. ADVANCED 브랜치에서는 더 많은 옵션을 제공합니다.

이 버전은 단순히 추억을 복원할 뿐 아니라, 더 자세하게, 그러면서 자유롭게 에뮬레이션 하는데 초점을 둡니다.

BASIC 버전이 피카소라면, ADVANCED 버전은 형체를 알아볼 수 없는 추상화입니다. 우리는 에뮬레이션이 '재현'이 아닌 '재해석'이 될 때 비로소 예술이 된다고 믿습니다.

"좀 더 대중적이고 안정적인 고통을 원하신다면 당장 BASIC 브랜치로 돌아가십시오."
